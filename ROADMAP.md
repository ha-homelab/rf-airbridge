# Roadmap

The current scope is the original RF extension, configuration examples, capture tools and bundled receiver code.
The README and changelog record implemented behavior and compatibility limits.

Next priorities: Keep the ESPHome patch aligned with its pinned upstream source; expand receive/transmit regression coverage and hardware acceptance; preserve sanitizer and TLS rejection tests.

Project-wide quality work includes a measured coverage baseline, independently
reviewed security evidence and complete source/release verification. Establishing
a real backup maintainer and testing recovery of publishing access remains open.
These are priorities, not promised delivery dates or completed badge criteria.
